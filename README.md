# Xolile Ngono — Personal Portfolio

A personal portfolio website showcasing my background, education, skills, interests, goals, and journey in digital marketing, artificial intelligence, and software development.

## About the Project

This website introduces me, Xolile Ngono, as a university student interested in digital marketing, artificial intelligence, technology, and creative problem-solving. It highlights my learning journey and provides a way for visitors to connect with me.

## Website Sections

- **Home** — Introduction and portfolio overview
- **About** — Background, interests, and approach to learning
- **Tech Journey** — My developing interests in web, mobile, software, and AI
- **Education** — University studies and high-school achievement
- **Skills** — Development, professional, and creative skills
- **Projects** — Space to showcase current and future projects
- **Experience** — Volunteer experience
- **Achievements** — Academic recognition and future milestones
- **Interests** — Hobbies and creative interests
- **Goals** — Learning and career roadmap
- **Contact** — Contact details and a message form

## Getting Started

### 1. Download or clone the project

If the project is hosted on GitHub, clone it with:

```bash
git clone <your-repository-url>
```

Or download the project files to your computer.

### 2. Keep the files organised

Make sure the project includes the HTML file and its supporting assets. A typical structure is:

```text
portfolio/
├── index.html
├── style.css
├── script.js
├── images/
│   └── image3.jpeg
└── README.md
```

The filenames and folder structure should match the paths used in the HTML and JavaScript.

### 3. Run the website

Open `index.html` in a web browser. For local development, you can also use Visual Studio Code with the Live Server extension.

## Customisation Notes

Before publishing, check these items:

- **Profile photo:** Update the image path in `index.html` to a relative path such as `images/image3.jpeg`. Avoid using a local Windows file path, because it will not work for visitors on other computers.
- **Projects:** Replace the sample project placeholders with real projects and add repository or live-demo links.
- **Social links:** Add the correct LinkedIn and GitHub URLs to the contact section.
- **Contact form:** The current form needs a service such as Formspree or EmailJS, or a backend, to send messages. Connecting a form service is a separate setup step.
- **Content:** Review the wording, spelling, and study details before publishing.

## Deployment

This is a static website and can be hosted using services such as GitHub Pages, Netlify, or Vercel. Follow the hosting provider's instructions and upload the complete project, including the CSS, JavaScript, and image assets.
